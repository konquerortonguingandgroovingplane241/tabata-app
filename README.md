# Tabata App ⏱️

A minimal, elegant, and easy-to-use Tabata timer to organize and optimize your workouts, whether at home or in the gym.  
Designed with a modern _dark mode_ interface to reduce eye strain and maximize focus during intense sessions.

## 🛠 Built With

- **[Vue 3](https://vuejs.org/)**: A reactive and performant framework for the user interface.
- **[Plus Ultra](https://github.com/Domenico-Tenace-Open-Labs/plus-ultra)**: A UI library based on Bulma CSS with full native support for Dark Mode.
- **[Capacitor](https://capacitorjs.com/)**: A cross-platform native runtime to convert the web app into a native mobile app.

## 🚀 Getting Started

1. Clone the repository or download the files.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
